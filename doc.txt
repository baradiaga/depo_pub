Guide de Mise en Production : Projet MOSCEPA
1. Préparation du Frontend (Angular)
L'objectif est de transformer le code TypeScript en fichiers statiques optimisés (HTML/JS/CSS).
Configuration des environnements :
Fichier : src/environments/environment.prod.ts.
Action : Centraliser l'URL de l'API réelle (apiUrl: 'api.votre-domaine.com').
Services :
Action : Remplacer toutes les URLs fixes par la variable ${environment.apiUrl}.
Génération du Build :
Commande : ng build --configuration production.
Résultat : Les fichiers sont générés dans le dossier dist/fronten/browser.
Déploiement Web :
Action : Copier le contenu de browser vers le dossier racine du serveur web (ex: /var/www/html sur Linux ou htdocs sur XAMPP).
Fallback Routage : Créer un fichier .htaccess (Apache) ou configurer Nginx pour rediriger toutes les requêtes vers index.html.
2. Préparation du Backend (Spring Boot)
L'objectif est de créer un exécutable sécurisé et indépendant.
Externalisation de la configuration :
Fichier : application.properties.
Action : Utiliser des variables d'environnement (${DB_PASS:default}) pour les mots de passe, les ports et les chemins de stockage (uploads).
Sécurité (CORS) :
Action : Dans SecurityConfig.java, autoriser l'URL finale du frontend (ex: https://votre-domaine.com) pour permettre la communication.
Compilation :
Commande : .\mvnw.cmd clean package -DskipTests.
Résultat : Un fichier .jar (ex: moscepa-backend-1.0.0.jar) dans le dossier target/.
3. Déploiement sur un Serveur Réel (VPS/Cloud)
Voici les étapes à suivre pour une installation professionnelle en 2026 :
Étape A : Infrastructure
Hébergement : Louer un VPS (Linux Ubuntu recommandé).
Installation : Installer Java 17+ (JRE) et un serveur de base de données (MySQL).
Certificat SSL : Utiliser Let's Encrypt pour activer le HTTPS (obligatoire).
Étape B : Lancement du Backend
Ne lancez pas le backend manuellement. Utilisez un gestionnaire de processus pour qu'il redémarre automatiquement.
Outil recommandé : PM2 ou systemd.
Commande type :
java -jar app.jar --spring.datasource.password=SECRET --server.port=8080
Étape C : Serveur Web (Nginx)
Utilisez Nginx comme "Reverse Proxy" :
Il reçoit les requêtes HTTPS (port 443).
Il sert les fichiers Angular directement.
Il redirige les appels /api vers Spring Boot (port 8080).
4. Maintenance et Sécurité
Dossier Uploads : Assurez-vous que le dossier spécifié dans file.upload-dir possède les droits d'écriture pour l'utilisateur qui lance le JAR.
Base de données : Effectuez des sauvegardes quotidiennes (automatisées via un script mysqldump).
Logs : Surveillez les fichiers de logs pour détecter d'éventuelles erreurs de production.
Synthèse des Commandes Clés
Action	Commande
Build Frontend	ng build --configuration production
Build Backend	.\mvnw.cmd clean package -DskipTests
Lancement Auto	.\run-moscepa.ps1 (Windows) ou pm2 start (Linux)
